# RideGo – Bike Rental Website

RideGo is a modern and responsive bike rental website that allows users to explore different bike categories, view rental plans, select locations, and calculate rental prices. The project focuses on creating a clean, interactive, and user-friendly frontend experience.

## Features

* Responsive navigation with mobile menu
* Attractive hero section
* Quick bike booking section
* Bike categories and featured bikes
* Bike filtering by category
* Rental plans with different durations
* Dynamic rental price calculator
* Multiple rental locations
* Bike specifications and pricing
* How It Works section
* Rental features and benefits
* Customer reviews
* Interactive FAQ section
* Contact form
* Newsletter subscription
* Responsive layout for different screen sizes

## Technologies Used

* HTML5
* Tailwind CSS
* JavaScript

## JavaScript Features

JavaScript is used to provide interactive functionality throughout the website:

* Bike category filtering
* Rental price calculation
* Location selection

## Getting Started

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Explore the RideGo bike rental website.

## Purpose

This project was created to practice frontend development, responsive design, Tailwind CSS, and JavaScript DOM manipulation while building a realistic bike rental website.
